# Enterprise Foundation Layer

This directory contains dormant enterprise scaffolding for future ZWAP expansion.

Purpose:
- prepare organization support early
- avoid backend refactors later
- support future grants, pilots, employer programs, and analytics

This layer should NOT alter current V1 user experience.

Current scope:
- organization schema
- organization membership schema
- base service helpers
- constants and validation helpers

Deferred until post-V1:
- enterprise dashboard
- organization analytics UI
- family wellness flows
- burnout check-ins
- privacy/compliance controls
- employer/admin portals
